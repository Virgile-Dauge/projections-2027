- [[pyei-a-python-package-for-ecological-inference]] — PyEI: A Python package for ecological inference — JOSS paper (Knudson, Schoenbach & Becker 2021, MGGG Redistricting Lab / Tufts) introducing PyEI, an open-source Python package unifying multiple ecological inference methods used in US voting rights litigation: Goodman's ecological regression (1953) plus a Bayesian linear variant, King's (1997) truncated-normal approach, Binomial-Beta hierarchical models (King et al. 1999), Dirichlet-Multinomial hierarchical models (Rosen et al. 2001), and a Wakefield (2004) Bayesian hierarchical 2x2 method. Frames EI as an 'R by C' table-margin inference problem (e.g. inferring what % of East Asian voters voted for each of 3 candidates from precinct-level vote totals and demographic marginals only — an underdetermined system requiring statistical assumptions). Built on PyMC3/NUTS gradient-based MCMC for faster convergence than existing R implementations. Explicitly positions itself alongside R packages eiPack, RxCEcolInf, King's own 'ei' package, and eiCompare as tools for quantifying uncertainty, comparing methods, and running diagnostics — the same diagnostics whose reliability Freedman et al. dispute. Useful as an open-source EI toolchain reference for the France bureau-de-vote projection use case, though built for the 2-group racial-bloc-voting US legal context rather than multi-party French elections. `evergreen`
